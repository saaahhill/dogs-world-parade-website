# Dog's World India — Independence Day Pet Parade

Landing page for the Independence Day Pet Parade event by Dog's World India.

- **Date:** Saturday, 15 August 2026, 8:00 AM
- **Route:** Dr. Kashinath Ghanekar Natyagruha → Dog's World India, Manpada (~600 m)
- **Pass:** ₹299 per pet + one parent

## Structure

- `index.html` — single self-contained page (styles + script inline)
- `assets/logo.png` — Dog's World India logo
- `assets/map.jpg` — route map graphic

## Deploy

Drag this folder onto [app.netlify.com/drop](https://app.netlify.com/drop), or connect this repo to Netlify/Vercel for auto-deploys on push.

Before going live, set the payment link in `index.html` (search for `PAYMENT_URL`).
